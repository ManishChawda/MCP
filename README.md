# MCP - Model Context Protocol

This repository contains examples and learning exercises for the Model Context Protocol (MCP) using Python.

## Overview

The project demonstrates how MCP servers can expose tools and data to AI assistants and Large Language Models (LLMs).

Examples include:

* Basic MCP Servers
* Infrastructure Information Tools
* Sophos API Integration
* Firewall Information Retrieval
* Tool Registration and Execution

## Project Files

* `mcp_basic-info-server-1.py`
* `mcp_basic-info-server-2.py`
* `mcp_infra-server.py`
* `mcp_sophosapi_1.py`
* `mcp_sophosapi_2.py`

## Requirements

* Python 3.11+
* MCP SDK
* Requests

## Installation

```bash
pip install -r requirements.txt
```
